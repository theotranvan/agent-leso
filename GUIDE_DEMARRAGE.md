# 🚀 AGENT LESO — Guide de démarrage (Conti)

Bienvenue ! Ce guide vous permet de démarrer en 5 minutes.

---

## 1. Connexion (1 min)

1. Ouvrez **[URL de votre espace]** dans votre navigateur (Chrome/Edge de préférence)
2. Entrez votre **email** (`prenom.nom@conti-ing.ch`) et le **mot de passe** qui vous a été transmis
3. Vous arrivez sur le **tableau de bord**
4. *(Conseil)* Changez votre mot de passe : menu **Paramètres**

> Vous travaillez tous dans **le même espace** : les projets et livrables créés par un collègue sont visibles par toute l'équipe.

---

## 2. Créer une affaire (1 min)

1. Menu **Mes projets** → **Nouveau projet**
2. Renseignez : **nom**, **canton** (GE, VD…), **affectation** (logement collectif…), adresse
3. Enregistrez

L'affaire devient le contexte de vos livrables (le canton adapte automatiquement les contrôles réglementaires).

---

## 3. Les modules — par où commencer

### ⚡ Pour un résultat immédiat (sans fichier)
| Module | Ce qu'il produit | Où |
|---|---|---|
| **Simulation énergétique rapide** | Qh estimé en 30 s depuis le programme | Sidebar → *Générer un livrable* → carte Simulation |
| **Thermique SIA 380/1** | Justificatif thermique | Sidebar → **Thermique SIA** |
| **Contrôle réglementaire** | Rapport pré-dépôt (zone, énergie, LDTR, AEAI…) | *Générer un livrable* → Contrôle |

### 📄 Livrables documentaires
| Module | Produit |
|---|---|
| **CCTP** / **DPGF** | Descriptif & chiffrage par lot |
| **Dossier mise en enquête** | Mémoire justificatif APA/APC |
| **Réponse aux observations** | Lettre argumentée depuis un courrier DALE/CAMAC (upload PDF) |
| **Compte-rendu de réunion** | Synthèse depuis vos notes |

### 🇨🇭 Modules suisses dédiés (sidebar)
| Module | Usage |
|---|---|
| **IDC Genève** | Ajoutez un bâtiment → ouvrez-le → **téléversez les factures** → calcul IDC + formulaire OCEN |
| **AEAI (incendie)** | Nouvelle checklist (typologie + canton) → **Exporter PDF** = rapport AEAI |
| **Métrés IFC** | Upload d'un IFC → surfaces SIA 416 + DPGF Excel pré-rempli |
| **Pré-BIM** | Génère une maquette IFC depuis un programme texte |
| **Coordination inter-lots** | *Générer un livrable* → ajoutez 2+ IFC (un par lot) → détection de conflits + BCF |

---

## 4. Suivre et valider vos livrables

1. Chaque tâche passe par : **En attente → En cours → Terminée**
   *(la toute première du matin peut mettre ~1 min : le service se « réveille »)*
2. Ouvrez la tâche terminée → **téléchargez le PDF / Excel**
3. Onglet **À valider** → relisez → **Approuvez**
4. Sur une affaire, **Dossier complet** assemble les livrables approuvés en **ZIP**

---

## 5. Bon à savoir

- **Chaque livrable est une aide à la production** : l'ingénieur signataire reste responsable du contrôle final.
- Un **score de confiance** indique les points à relire en priorité.
- **Quota** : le plan inclut un nombre de tâches/mois partagé par l'équipe (visible dans *Facturation*).
- **Un souci ?** Notez l'écran + le message et signalez-le — correction rapide.
